# NovaFood · Gestor de pedidos

Gestor web de pedidos de restaurante con catálogo, carrito, productos e historial.

Proyecto académico de desarrollo web.

## Funcionalidades

- Catálogo de productos, búsqueda, categorías y carrito de compras.
- Cálculo de pedidos y descuentos, con historial y facturas.
- Administración de productos e indicadores de ventas.

## Tecnologías

HTML5, CSS3 y JavaScript (ES6+), Bootstrap 5.

## Ejecución local

Desde la carpeta del proyecto, inicia un servidor estático:

```sh
python -m http.server 8000
```

Abre [http://localhost:8000](http://localhost:8000) en tu navegador. También puedes usar Live Server de Visual Studio Code.

## Notas

Utiliza Bootstrap desde CDN; se necesita conexión a internet para cargar esa dependencia.
